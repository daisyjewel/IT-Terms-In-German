# 🇩🇪 TechDeutsch: German-English-Indonesian IT Glossary
*Kamus istilah teknologi, informasi, dan pemrograman dari bahasa Jerman ke bahasa Inggris dan Indonesia.*

> [!TIP]
> **Cara Cepat Cari Istilah (Schnellsuche):**
> 1. Tekan tombol **`Ctrl + F`** pada keyboard kamu.
> 2. Ketik kata yang dicari dalam bahasa Jerman, Inggris, atau Indonesia (misal: `Verschlüsselung` atau `encryption`).

## 🅰️ A - D

| Deutsch (German) | English | Indonesia | Penjelasan & Contoh Konteks |
| :--- | :--- | :--- | :--- |
| **der Browserverlauf** | Browser history | Riwayat penjelajahan | Daftar situs web yang pernah dikunjungi di browser.<br>*Konteks: "Ich muss meinen Browserverlauf löschen." (I need to clear my browser history).* |
| **die Datei** | File | Berkas / Dokumen | Kumpulan data digital yang disimpan dalam media penyimpanan. |
| **der Datenschutz** | Data privacy / protection | Perlindungan data | Regulasi atau upaya melindungi data pribadi agar tidak disalahgunakan. |

## 🅴 E - H

| Deutsch (German) | English | Indonesia | Penjelasan & Contoh Konteks |
| :--- | :--- | :--- | :--- |
| **die Fehlermeldung** | Error message | Pesan kesalahan | Pemberitahuan dari sistem bahwa terjadi masalah dalam program. |
| **gehackt werden** | To be hacked | Diretas / Kena retas | Kondisi ketika sistem atau akun ditembus secara ilegal oleh pihak luar.<br>*Konteks: "Mein E-Mail-Konto wurde gehackt." (My email account was hacked).* |
| **herunterladen** | To download | Mengunduh / Download | Proses menyalin data dari server internet ke komputer lokal. |

## 🆂 S - V

| Deutsch (German) | English | Indonesia | Penjelasan & Contoh Konteks |
| :--- | :--- | :--- | :--- |
| **der Serverraum** | Server room | Ruang server | Ruangan khusus yang digunakan untuk menyimpan komputer server dan perangkat jaringan.<br>*Konteks: "Der Zutritt zum Serverraum ist strengstens verboten." (Access to the server room is strictly prohibited).* |
| **speichern** | To save | Menyimpan | Proses mengamankan perubahan data ke dalam penyimpanan digital. |
| **die Verschlüsselung** | Encryption | Enkripsi / Persandian | Proses mengubah data menjadi kode rahasia agar tidak bisa dibaca tanpa kunci khusus.<br>*Konteks: "Ende-zu-Ende-Verschlüsselung" (End-to-end encryption).* |

## 🆆 W - Z

| Deutsch (German) | English | Indonesia | Penjelasan & Contoh Konteks |
| :--- | :--- | :--- | :--- |
| **das Passwort** | Password | Kata sandi | Kode rahasia untuk memverifikasi identitas pengguna saat login. |
| **der Zugriff** | Access | Akses / Hak masuk | Izin atau kemampuan untuk membuka dan menggunakan data/sistem.<br>*Konteks: "Zugriff verweigert" (Access denied) atau "Zugriff erlaubt" (Access granted).* |
| **die Zwischenablage** | Clipboard | Papan klip | Tempat penyimpanan sementara saat melakukan copy (salin) data.<br>*Konteks: "In die Zwischenablage kopiert" (Copied to clipboard).* |
